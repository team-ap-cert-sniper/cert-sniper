## 오늘의 사자성어 (CF-00-04, CF-04-19)

| 항목 | 기준 |
|---|---|
| 목록 | 팀 제공 50개. [etl/data/daily_idioms.csv](../etl/data/daily_idioms.csv)에 두고 초기 적재 도구가 `daily_idioms`에 넣는다 (`display_order` 1~50) |
| 순서 | 기준일(설정값 `application.yml`, 현재 **2026-01-01**)에 1번, 다음 날 2번 … 50번 다음 날 다시 1번. 하루 1개씩 순서대로, 50일 주기로 순환한다 |
| 날짜 | 서버가 계산한 **한국시간 오늘**. 로그인 여부, 회원, 메인·플래너 화면, 플래너에서 고른 날짜와 관계없다 |
| 같은 결과 | 날짜만으로 정해지므로 모든 사용자에게 같은 사자성어가 나온다. 날짜별로 저장하는 테이블은 없다 |
| 캐시 | 서버는 날짜를 키로 결과를 캐시해 하루 1번만 DB를 읽는다 |
| 없음 | 항목이 없으면 빈 상태를 표시한다 |

API: `GET /api/v1/daily-idiom` → `{date, display_order, idiom, hanja, meaning, cycle_days}` (planner 패키지 `DailyIdiomController`, 로그인 불필요)

처리 순서 (백엔드 `DailyIdiomService`, 기준 구현 `etl/jeogyeokjeung/service.py`의 `daily_idiom()`)

1. 한국시간 오늘 날짜를 계산한다
2. 캐시에 그 날짜가 있으면 바로 반환한다
3. 50개를 `display_order` 순으로 읽는다 (`UQ(display_order)`)
4. (오늘 − 기준일)의 일수를 전체 건수(50)로 나눈 나머지 번째 항목을 고른다 (0이면 1번)
5. 캐시에 넣고 반환한다

예: 2026-01-01 → 1번 우공이산, 2026-02-19 → 50번 자수성가, 2026-02-20 → 1번 우공이산, 2026-11-20 → 24번 언행일치

## 저격왕 합격수기: 합격 구분 삭제

`pass_stories.pass_stage`(합격 구분)와 그 CHECK를 뺐다. 자격증 선택과 본문은 그대로 필수다. 시험일정·시험과목·합격률이 쓰는 시험 단계(`exam_stage`: 필기·실기·1차·2차·3차·면접·시험)는 그대로 둔다.

| 적용 위치 | 수정 내용 |
|---|---|
| CF-05-05 카드·상세, CF-01-12 추천 페이지 합격수기 미리보기 | 합격 구분 표시 삭제 |
| CF-05-06 등록, CF-05-07 수정, CF-05-10 숨김 글 수정 | 입력 폼과 요청·응답 DTO에서 합격 구분 삭제 |
| CF-05-03 내가 쓴 글, ADMIN-11 관리자 저격왕 목록 | 같은 카드 데이터를 쓰므로 합격 구분 표시 삭제 |

## 저격왕 합격수기: 과목별 체감 난이도 삭제

`pass_story_subject_difficulties`(과목별 체감 난이도)와 과목 목록 테이블 `qualification_subject_items`를 뺐다. 합격수기 선택 항목은 응시자 베이스·준비 기간·응시 횟수·교재명·합격 점수·응시일이다. 시험과목은 `qualifications.exam_subjects`(원문)로 자격증 상세와 AI 플래너에 쓴다.

| 적용 위치 | 수정 내용 |
|---|---|
| CF-05-06 등록, CF-05-07 수정, CF-05-05 상세 | 과목별 체감 난이도 입력·표시 삭제 |
| CF-05-12 승급 알림 | 알림 테이블 없이 합격수기 등록 응답의 이전·새 등급으로 팝업 |
